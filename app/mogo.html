현재 클라우드 엔진 탑재 완료 (자동 감지 모드)

현재 이 HTML 파일에는 실시간 클라우드 저장소(Firebase Firestore) 연동 코드가 이미 내장되어 있습니다. 현재 미리보기 환경에서는 즉시 클라우드에 자동 저장되며, 추후 GitHub Pages에 올리실 때는 아래 3단계만 거치면 됩니다.

🚀 GitHub Pages 배포 시 실시간 DB 연결 3단계

  1. Firebase 무료 프로젝트 생성: console.firebase.google.com 접속 후 무료 프로젝트 생성 → Firestore Database 활성화 및 Authentication(익명 로그인) 허용
  2. Config 키 복사: 프로젝트 설정에서 웹 앱(</>) 추가 후 발급되는 firebaseConfig 객체 복사
  3. HTML 파일 내 입력: 이 HTML 코드 하단 스크립트의 CUSTOM_FIREBASE_CONFIG 변수에 붙여넣고 GitHub 저장소에 Push하면 모든 기기에서 실시간 동기화됩니다!
